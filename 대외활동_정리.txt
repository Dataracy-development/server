대외활동 정리


1. KUSITMS (한국대학생IT경영학회)

활동 기간: 2024.02 ~ 2024.12 (11개월)

활동 내용과 본인의 역할, 기여도:

KUSITMS 30기 백엔드 개발파트와 경영총괄팀 운영진으로 활동하며 기술 역량 향상과 학회 운영에 기여했습니다.

백엔드 개발파트에서는 Java/Spring Boot 기반 백엔드 개발을 학습하고 실습했습니다. 3개의 팀 프로젝트(Lets-Career, HitZone, Dataracy)에 참여하여 실무 수준의 백엔드 개발 경험을 쌓았습니다. 특히 산학협력 프로젝트인 Lets-Career에서 QueryDSL과 Redis 캐싱을 활용한 성능 최적화로 응답 속도를 99.4% 단축시켰고, 이 성과를 바탕으로 최우수상을 수상했습니다.

경영총괄팀 운영진으로서 30기 기수 운영 및 학회원 관리를 담당했습니다. 약 100여 명의 학회원들의 활동을 관리하고, 프로젝트 팀 매칭, 세션 일정 조율, 학회 행사 기획 및 진행을 맡았습니다. 학회원들 간 원활한 소통을 위해 Notion과 Slack을 활용한 협업 시스템을 구축했고, 정기 회의를 주도하며 학회 운영의 효율성을 높였습니다.

백엔드 개발자 20~30명을 대상으로 QueryDSL 기술 세션을 발표했습니다. "QueryDSL과 캐시를 통한 쿼리 최적화"라는 주제로 N+1 문제 해결, Keyset Pagination, Redis 캐싱 전략 등 실제 프로젝트에서 달성한 성능 개선 사례를 공유했습니다. 발표 후 다른 개발자들로부터 실무 적용에 대한 질문을 많이 받았고, 일부는 자신의 프로젝트에 적용했다는 피드백을 받았습니다.

학회 활동을 통해 백엔드 개발 역량을 크게 향상시켰고, 9인 팀 협업 경험을 2회 쌓으며 협업 능력을 발전시켰습니다. 또한 운영진으로서 리더십과 커뮤니케이션 능력을 기를 수 있었습니다.


2. 산학협력 프로젝트 - 렛츠커리어 (Lets-Career)

활동 기간: 2024.08 ~ 2024.09 (1~2개월)

활동 내용과 본인의 역할, 기여도:

렛츠커리어와의 산학협력 프로젝트로 MAU(월간 활성 사용자) 상승을 목표로 취업 관리 대시보드 개선 과제를 수행했습니다.

백엔드 개발자 2명 중 1명으로 참여하여 채용 일정 관리, 대시보드, 알림 시스템, 투두 리스트, 자기소개서 관리 등 핵심 기능을 개발했습니다. 채용 일정 관리 시스템에서는 기업별 일정과 전형 단계별(서류, 필기, 면접) 등록/수정/삭제 기능을 구현했고, 대시보드에서는 관심 기업 목록, 마감 임박 정렬, D-DAY 자동 계산 기능을 제공했습니다.

Spring Scheduler를 활용한 배치 알림 시스템을 구축했습니다. 매일 오전 9시에 스케줄러가 실행되어 마감 3일 전인 일정을 조회하고 해당 사용자들에게 알림을 전송하도록 구현했습니다. 알림 히스토리를 DB에 저장하여 중복 알림을 방지했고, 사용자별 알림 설정 관리 기능도 추가했습니다.

성능 최적화에 집중했습니다. 대시보드 조회 시 평균 650ms가 소요되는 문제를 발견하고, QueryDSL 도입으로 타입 안전한 동적 쿼리를 작성했습니다. Keyset Pagination을 적용하여 대용량 데이터 페이징을 개선했고, Redis 캐싱으로 반복 조회를 최적화했습니다. 결과적으로 응답 속도를 650ms에서 4ms로 99.4% 단축시켰고, 메모리 사용량도 305MB에서 273MB로 10% 감소시켰습니다.

RestDocs와 Swagger를 연동하여 API 테스트 코드 작성을 통한 자동 문서화 시스템을 구축했습니다. 이를 통해 프론트엔드 팀과의 협업 효율성을 크게 향상시켰고, API 명세 불일치로 인한 오류를 사전에 방지할 수 있었습니다.

기술적 완성도와 대시보드 개선 아이디어를 인정받아 최우수상(1위)을 수상했습니다. 렛츠커리어 측으로부터 "실무에 바로 적용 가능한 수준"이라는 평가를 받았고, 실제로 일부 기능이 서비스에 반영되었습니다. 이 프로젝트를 통해 비즈니스 목표(MAU 상승)를 기술로 해결하는 능력을 기를 수 있었습니다.


3. 세종대학교 졸업 프로젝트

활동 기간: 2024.03 ~ 2024.06 (4개월)

활동 내용과 본인의 역할, 기여도:

졸업 프로젝트 팀 리더(PM)로서 팀 구성부터 프로젝트 완수까지 전체 과정을 주도했습니다.

에브리타임 플랫폼을 통해 팀원을 모집했습니다. 프로젝트 아이디어와 기술 스택을 명확히 제시한 모집 글을 작성하여 적합한 팀원 4명을 선발했습니다. 창업 아이디어를 주제로 선정하고 시장 조사를 진행했으며, 타겟 유저 인터뷰를 통해 프로젝트 방향성을 구체화했습니다.

PM으로서 프로젝트 전체 일정을 관리하고 팀원들의 역할을 분배했습니다. 주 2회 정기 회의를 주도하며 진행 상황을 점검했고, Notion으로 작업 내용을 문서화하여 팀원 간 정보 공유를 원활하게 했습니다. Git Flow 브랜치 전략을 도입하여 버전 관리 체계를 확립했습니다.

팀원 간 기술 격차 문제를 해결했습니다. 일부 팀원의 기술 수준이 예상보다 낮아 프로젝트 진행이 지연되는 상황이 발생했습니다. 이에 역할을 재분배하고, 기술 스터디 세션을 주 1회 진행하여 지식을 공유했습니다. 코드 리뷰를 통해 팀원들의 코드 품질을 점진적으로 개선했고, 페어 프로그래밍으로 어려운 부분을 함께 해결했습니다.

프론트엔드 개발을 직접 담당했습니다. React + TypeScript 기반으로 웹 애플리케이션을 개발했고, UI/UX 설계에도 참여했습니다. 백엔드 팀원과 API 명세를 협의하고, RESTful API 설계 원칙을 공유하며 협업했습니다.

프로젝트를 성공적으로 완수하여 졸업 요건을 충족했습니다. 팀 리더로서 팀원들을 이끌며 리더십과 문제 해결 능력을 크게 향상시켰고, 프론트엔드와 백엔드를 모두 경험하며 풀스택 개발에 대한 이해도를 높였습니다. 이 경험을 바탕으로 백엔드 개발로 전향하는 계기를 마련했습니다.


4. 프론트엔드 개발 활동

활동 기간: 2023.03 ~ 2024.06 (1년)

활동 내용과 본인의 역할, 기여도:

React + TypeScript 기반 웹 애플리케이션 개발 경험을 쌓으며 3개의 프로젝트에서 수상했습니다.

KUSITMS 29기에서 첫 팀 프로젝트를 진행했습니다. 프론트엔드 개발자로 참여하여 React 컴포넌트 설계, 상태 관리(Redux), API 연동 등을 담당했습니다. TypeScript를 활용하여 타입 안전성을 확보했고, Styled-Components로 반응형 UI를 구현했습니다. 이 프로젝트에서 장려상을 수상했습니다.

멋쟁이사자처럼 11기 해커톤에 참여했습니다. 24시간 동안 아이디어 기획부터 개발, 발표까지 완수하는 경험을 했습니다. 팀원 4명과 협업하여 소셜 네트워킹 서비스를 개발했고, 프론트엔드 전체를 담당했습니다. 짧은 시간 내에 MVP를 완성하는 빠른 실행력을 발휘했고, 우수상을 수상했습니다.

Cotato IT 동아리 프로젝트에서 팀 리더로 활동했습니다. 5인 팀을 구성하고 프로젝트 방향성을 제시했으며, UI/UX 설계부터 프론트엔드 개발까지 주도했습니다. Figma로 디자인 시스템을 구축하고, Storybook으로 컴포넌트 문서화를 진행했습니다. 이 프로젝트에서 대상을 수상했습니다.

백엔드-프론트엔드 협업 이해도를 쌓았습니다. 백엔드 개발자들과 API 명세를 협의하며 RESTful API 설계 원칙을 학습했고, Swagger 문서를 활용한 효율적인 협업 방법을 익혔습니다. CORS, 인증/인가 등 프론트엔드에서 겪는 백엔드 관련 이슈를 직접 경험하며, 백엔드 개발에 대한 관심을 갖게 되었습니다.

UI/UX 설계 역량을 키웠습니다. 사용자 중심 설계(User-Centered Design) 원칙을 적용했고, 사용성 테스트를 통해 피드백을 수집하고 개선했습니다. 이 경험은 백엔드 개발로 전환한 후에도 API 설계 시 사용자(프론트엔드 개발자) 관점을 고려하는 데 큰 도움이 되었습니다.

프론트엔드 경험을 바탕으로 2024년 6월부터 백엔드 개발로 전환했습니다. 프론트엔드와 백엔드를 모두 경험하며 풀스택 개발에 대한 이해도를 갖추게 되었고, 이는 백엔드 개발 시 프론트엔드와의 협업에서 큰 강점이 되었습니다.


5. ALOM (세종대학교 IT동아리)

활동 기간: 2022.03 ~ 2024.06 (2년 4개월)

활동 내용과 본인의 역할, 기여도:

세종대학교 IT 학술 동아리 ALOM에서 프로그래밍 기초부터 Spring까지 체계적으로 학습했습니다.

1학년(2022.03 ~ 2023.02): C언어 스터디에 참여하여 프로그래밍 기초를 다졌습니다. 매주 알고리즘 문제 풀이를 진행했고, 백준 온라인 저지에서 100문제 이상을 해결했습니다. 포인터, 구조체, 파일 입출력 등 C언어의 핵심 개념을 학습하며 저수준 프로그래밍에 대한 이해도를 높였습니다.

2학년(2023.03 ~ 2024.02): 자료구조 스터디를 주도했습니다. 배열, 연결 리스트, 스택, 큐, 트리, 그래프 등 주요 자료구조를 직접 구현하며 학습했고, 시간 복잡도와 공간 복잡도 분석 능력을 키웠습니다. 스터디 자료를 정리하여 동아리원들과 공유했고, 알고리즘 문제 풀이 세션을 매주 진행했습니다.

3학년(2024.03 ~ 2024.06): Spring 스터디에 참여하여 백엔드 개발의 기초를 학습했습니다. Spring Boot, Spring MVC, JPA 등을 실습하며 웹 애플리케이션 개발 방법을 익혔습니다. 간단한 CRUD 게시판을 직접 구현하며 RESTful API 설계, 데이터베이스 연동, 인증/인가 등을 학습했습니다. 이 경험이 KUSITMS에서 백엔드 개발로 활동하는 기반이 되었습니다.

동아리 활동을 통해 프로그래밍 기초부터 웹 개발까지 체계적으로 학습 경로를 밟을 수 있었습니다. 특히 자료구조 스터디를 주도하며 학습 내용을 다른 사람에게 설명하는 능력을 키웠고, 이는 이후 KUSITMS에서 기술 세션 발표를 하는 데 큰 도움이 되었습니다.

정량적 성과 요약

KUSITMS: 백엔드 개발 3개 프로젝트 참여, 최우수상 1회 수상, 기술 세션 발표(20~30명 대상), 학회 운영진(100여 명 관리)
산학협력: 성능 최적화 99.4%, 메모리 사용량 10% 감소, 최우수상 수상
졸업 프로젝트: PM으로 4개월 프로젝트 완수, 팀원 5명 리드, 기술 격차 해결
프론트엔드: 3개 프로젝트 수상(대상, 우수상, 장려상), React + TypeScript 1년 경험
ALOM: 2년 4개월 활동, C언어, 자료구조, Spring 스터디 참여 및 주도

이 활동들을 통해 배운 것

기술적으로는 프론트엔드에서 백엔드로 전환하며 풀스택 개발에 대한 이해도를 갖추게 되었습니다. C언어와 자료구조로 프로그래밍 기초를 다지고, React로 웹 개발을 경험한 후, Spring으로 백엔드 개발 역량을 키웠습니다.

협업 능력을 크게 향상시켰습니다. 9인 팀 프로젝트를 2회 경험하며 Git Flow, 코드 리뷰, API 명세 협의 등 실무 협업 방식을 익혔고, PM 경험을 통해 팀을 이끄는 리더십도 기를 수 있었습니다.

지식 공유의 가치를 깨달았습니다. 자료구조 스터디 주도, QueryDSL 기술 세션 발표, 기술 블로그 작성 등을 통해 내가 배운 것을 다른 사람과 공유하며 함께 성장하는 즐거움을 느꼈습니다.

비즈니스 관점을 갖추게 되었습니다. 산학협력 프로젝트를 통해 기술이 비즈니스 목표(MAU 상승)를 달성하는 수단임을 이해했고, 사용자 가치를 먼저 생각하는 개발자로 성장했습니다.
