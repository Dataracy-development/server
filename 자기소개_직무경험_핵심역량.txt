직무 경험과 핵심 역량


2024년 6월부터 백엔드 개발에 집중하며 1년 4개월간 3개의 프로젝트를 통해 실무 수준의 기술 스택과 전체 개발 라이프사이클을 경험했습니다. 백엔드 전환 후 첫 프로젝트에서 최우수상을 수상하며 빠른 학습 능력과 기술적 완성도를 검증받았습니다.

Dataracy 프로젝트에서는 1인 백엔드 개발자로 아키텍처 설계부터 배포, 운영까지 전체를 담당했습니다. DDD + 헥사고날 아키텍처를 적용하고, Kafka 이벤트 기반 시스템과 Elasticsearch 검색 엔진을 구축했습니다. Redis 캐싱으로 API 응답 속도를 93.4% 개선했고, QueryDSL로 N+1 문제를 해결하여 쿼리 수를 97% 감소시켰습니다. Rate Limiting으로 무차별 대입 공격을 100% 차단했고, Projection Task Queue로 DB-ES 정합성을 100% 보장했습니다. 코드 품질 관리를 위해 ChatGPT API 기반 자동 리뷰 봇을 직접 제작하여 테스트 커버리지 82.5%, SonarQube A등급을 달성했습니다. Blue-Green 무중단 배포와 Prometheus + Grafana 모니터링으로 AWS에서 6개월간 실제 서비스를 운영했습니다.

Lets-Career 산학협력 프로젝트에서는 렛츠커리어의 MAU 상승이라는 비즈니스 목표를 달성하기 위해 대시보드를 개선했습니다. 취준생 인터뷰를 통해 페인 포인트를 파악하고, 대시보드 개선/알림 시스템/성능 최적화 세 가지 개선안을 제안했습니다. QueryDSL과 Redis 캐싱으로 응답 속도를 99.4% 단축시켰고, 최우수상을 수상했습니다. HitZone 프로젝트에서는 DDD 아키텍처 리팩토링을 주도하여 레이어 간 결합도를 낮췄고, OAuth2 3개 플랫폼 통합 인증을 구축했습니다.

2개월 만에 MVP를 출시하고 이후 실사용자를 대상으로 서비스를 운영하며 피드백 기반 개선 사이클을 구축했습니다. k6 부하 테스트로 10~800 VUs 환경에서 성능을 정량적으로 검증했고, 모든 최적화 작업을 데이터로 측정했습니다.


핵심 역량

성능 최적화 및 정량적 검증 - k6 성능 테스트로 모든 최적화를 정량적으로 검증합니다. Redis 캐싱으로 API 응답 속도 93.4% 개선, QueryDSL로 N+1 문제 해결하여 쿼리 97% 감소, Elasticsearch로 검색 속도 3배 향상을 달성했습니다. 사용자 피드백을 받아 문제를 파악하고 기술로 해결한 후 정량적 지표로 검증하는 사이클을 구축했습니다.

분산 시스템 아키텍처 설계 - Kafka 이벤트 기반 아키텍처로 비동기 처리 시스템을 구축하여 API 블로킹을 제거했고, Projection Task Queue + Worker 패턴으로 DB-ES 정합성을 100% 보장했습니다. Redisson 분산락으로 동시성 문제를 해결했고, DDD + 헥사고날 아키텍처로 장기적 유지보수를 고려한 확장 가능한 구조를 설계했습니다.

코드 품질 관리 - 테스트 커버리지 82.5%, SonarQube A등급을 달성하며 높은 코드 품질을 유지했습니다. 1인 개발 환경에서 ChatGPT API 기반 자동 코드 리뷰 봇을 Python Flask로 직접 제작하여 지속적인 피드백을 확보했고, JUnit5, Mockito로 단위/통합 테스트를 작성했습니다.

보안 및 DevOps - OAuth2 + JWT 소셜 로그인, Rate Limiting으로 무차별 대입 공격 100% 차단, AWS SES 이메일 인증을 구현했습니다. Blue-Green 무중단 배포, Prometheus + Grafana 실시간 모니터링, GitHub Actions CI/CD 자동화로 6개월간 실제 서비스를 안정적으로 운영했습니다.

비즈니스 관점 - 기술적 완성도는 높지만 비즈니스적으로 성공하지 못한 경험을 통해 "기술과 비즈니스의 균형"을 이해했습니다. 산학협력 프로젝트에서 MAU 상승이라는 비즈니스 목표를 기술로 해결하며 사용자 가치를 먼저 생각하는 개발자로 성장했습니다.

협업 및 지식 공유 - 9인 팀 프로젝트에서 PR마다 평균 20~30개, 최대 50개 이상의 코멘트를 주고받으며 활발한 코드 리뷰 문화를 확립했습니다. KUSITMS 백엔드 개발자 20~30명을 대상으로 QueryDSL 기술 세션을 발표했고, 30개 이상의 기술 블로그 포스팅으로 학습 내용과 트러블 슈팅을 공유했습니다.


사용자의 목소리를 존중하고 피드백을 기술로 증명하며, 데이터 기반으로 의사결정하는 백엔드 개발자입니다. 확장 가능하고 유지보수하기 좋은 코드를 작성하며, 기술로 실질적인 비즈니스 가치를 만들어내고자 합니다.
